# Compelling Ads and Creative

Read [shared policy](references/core-policy.md) first. Use [sources](references/sources.md) for current-source checks and boundaries.

1. Read the verified brand kit: name, audience, offer, voice, language, product images, logo, packaging, fonts, colors, approved claims and destinations. Do not infer missing prices or certifications. Use supplied assets with confirmed rights. If no brand kit exists, extract a draft from the brand's website (logo, colours, fonts, tone, products, offers, claims shown) and ask the owner to confirm it once; save the confirmed kit for every later run.
2. Generate three genuinely different concepts by default: demonstration/problem-solution, objection/education and credible evidence/comparison where permitted. Provide each concept's audience insight, source pattern, original hook, body, CTA, visual brief, landing message and success hypothesis. Avoid changing only adjectives.
   Recreating from a reference ad: keep only its structure (hook type, layout, pacing, offer framing, proof device) and replace every word, person, product, logo, scene and claim with the brand's own verified material. Record the reference link beside the new creative.
   Before production, score each concept 0–15 (0–3 each: pattern recency, competitor proof from winner signals, brand fit, production cost, expected cost per result). 11+ goes to the next test, 7–10 waits in the queue, 6 or less is revised or archived. The score orders the queue; only a live test decides.
3. Supply platform-specific text and aspect variants (9:16, 1:1, 4:5, 16:9 as each placement needs) after checking current provider requirements. For short video, write timed shots, narration, subtitles, product visibility, licensed audio requirements and a clear final CTA. Estimate narration at a natural pace, then validate actual duration from rendered audio; word count is not a timing test.
4. If a real image-generation tool is connected and authorized, create and inspect assets rather than calling a prompt an image. If unavailable, deliver usable copy, storyboard and production brief and label the asset generation BLOCKED. Konvert's published static-image capability does not prove a video-rendering service.
5. Inspect every generated asset for spelling, misleading visual claims, faces, hands, readable packaging, cropped logos, contrast, mobile readability, watermark, aspect ratio and product fidelity. Preserve uploaded identity and packaging. Use the existing rembg route for background removal in the user's apps.
6. Keep a creative ID and revision/hash per final asset. Any content or destination change invalidates its previous launch approval. Never fabricate testimonials, medical outcomes or guaranteed lead/sales results; apply health advertising review where relevant.

Deliver editable copy, actual available assets, alt text, caption/subtitle files when rendered, and a launch manifest. Do not include placeholder images or pretend narration was rendered when it was only scripted.
