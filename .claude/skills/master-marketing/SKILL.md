# Master Marketing Triage

Read [shared policy](references/core-policy.md) first. Use [sources](references/sources.md) for current-source checks and boundaries.

1. Read the shared policy and the live project instructions. Inspect the existing brand documents, current work, website, accounts and prior marketing memory; reuse authoritative facts. Do not ask Dan to choose skills.
2. Establish the business, offer, ideal customer, country/language, objective, funnel, margins and available channels. Infer safe draft defaults; mark unknown facts rather than inventing them. Missing brand URL prevents brand-specific launch, not research into tools.
3. Load marketing-skills-maintenance and marketing-connectors before substantive new work. Search current official sources for improved skills, APIs and competitors. Reuse a documented check under seven days old only if scope and dependencies are unchanged; record that choice. Security or auth changes force a fresh check.
4. Route automatically: competitor questions → marketing-ad-intelligence; positioning → marketing-strategy; ads/scripts → marketing-creative; posting → marketing-publishing; free media/search → marketing-organic; conversion → marketing-funnel; prospects → marketing-leads; nurture → marketing-sales; results → marketing-analytics; checks → marketing-quality. Load only selected skills.
5. Separate two watchlists: marketing-platform competitors (Konvert, Foreplay, Motion etc.) improve this toolkit; each customer's actual commercial rivals inform their campaigns. Never use the former as the customer's competitor list unless the customer sells marketing software.
6. Freeze a compact run record: run_id, brand_id, mode, goal/KPI, source timestamps, selected skill versions, decisions, budget/authority, constraints, acceptance checks and blockers. Continuations reuse it; scope changes update it. Store records outside app source unless authorized otherwise.
7. Research → explain opportunities → create original drafts → verify assets and funnel → execute only authorized actions with real connectors → reconcile receipts → measure qualified leads and sales → save lessons. Offer the three highest-impact next actions with effort, cost, expected mechanism and evidence strength.
8. If the original Master Skills v4 hook is active, retain its triage, freeze and Vercel rules. This marketing hook supplies context only; it does not override or replace that engine. Never label a failed or absent gate GREEN.

Produce a short daily digest: new/changed rival ads, proxy shortlist with evidence links, three original concepts, next approved experiment, organic opportunity, lead/sales movement, costs and blockers. A background schedule is a distinct setup task; use the monitoring reference.

Read [monitoring](references/monitoring.md) before claiming or setting up ongoing monitoring.

When the owner asks to track rivals every day and get clear winners recreated for the brand, run the winner → recreate → send loop in [monitoring](references/monitoring.md).

For a full brand campaign (competitor and organic research, pattern breakdown, original scripts, AI production brief and content calendar), follow the [Lookalike Campaign Engine](references/lookalike-campaign-engine.md). Fill its INPUTS from the project first; ask once only for what cannot be found.
